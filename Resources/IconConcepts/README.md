# CoderBar icon concepts

17 icon concepts exported as multi-resolution ICNS (16–1024 px), with 1024 px PNG previews.

01–12 were cropped from comparison sheets; the exterior background was removed with flood-fill or silhouette masks to preserve pale artwork. Their source artwork is roughly 500 px per icon, so larger representations are upscaled. The five standalone concepts preserve their original alpha. See `sources.json` for original generated image filenames and crop coordinates.

14-space-chocolate-coderbar is the latest requested combination: Space Chocolate with the Classic Red logo. These are alternatives; exporting them does not change the app build icon.

All ICNS files were decoded successfully with macOS sips.
